# SMILES Data (Case Study)

This folder contains the SMILES sources required to compute substructures for
the current case study (real_id 0–151).

## Files

- `HF-Literature.tsv`
  - Source dataset with SMILES columns (`product_1_smiles`, `ligand_1_smiles`,
    `startingmat_1_smiles`, `solvent_1_smiles`).
- `HF-Experimental.tsv`
  - Experimental dataset (not required for the current case study).
- `cas_to_original_mapping.json`
  - Maps `real_id` (0–151) → original row index in `HF-Literature.tsv`.
- `dimenet-10conf_split_0.json`
  - Train/val/test split used to rebuild the full 3518-row dataset with SMILES.
- `real_id_smiles.csv`
  - Generated by `build_real_id_smiles_map.py`.
  - Columns: `real_id`, `product_smiles`, `ligand_smiles`,
    `startingmat_smiles`, `solvent_smiles`.
- `latent-spaces/`
  - Raw SMILES-bearing CSVs copied from the `latent-spaces` repo for reference:
  - `latent-spaces/dimenet-10conf/checkpoint0/euclidean.csv`
  - `latent-spaces/dimenet-10conf/checkpoint0/tangent_space.csv`
  - `latent-spaces/dimenet-noaug/checkpoint0/euclidean.csv`
  - `latent-spaces/dimenet-noaug/checkpoint0/tangent_space.csv`
  - These files include `ligand_1_smiles` but do not directly map to `real_id`.

## Build the real_id → SMILES map

```bash
python latentvis/backend/scripts/build_real_id_smiles_map.py
```

## Compute substructures (MCS)

```bash
python latentvis/backend/scripts/generate_cluster_substructures.py \
  --topk-json latentvis/frontend/public/data/topk/cluster_representatives.json \
  --smiles-csv latentvis/backend/data/smiles/real_id_smiles.csv \
  --id-column real_id \
  --smiles-column product_smiles \
  --out latentvis/frontend/public/data/substructures/cluster_substructures.json
```

If you want to use a different SMILES type, change `--smiles-column` to one of:

- `ligand_smiles`
- `startingmat_smiles`
- `solvent_smiles`
